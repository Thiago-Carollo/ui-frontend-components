# 🎨 UI & Frontend Components Collection

Colección modular de componentes de interfaz de usuario (UI), maquetas web y efectos visuales interactivos desarrollados con HTML, CSS, SCSS y JavaScript.

---

## 📂 Catálogo de Componentes (Demos en vivo)

| Componente | Descripción | Tecnologías | Probar en vivo |
| :--- | :--- | :---: | :---: |
| **🧮 Calculator** | Calculadora interactiva con selector de modo claro y oscuro. | HTML, SCSS, JS | [Ver demo 🌐](https://thiago-carollo.github.io/ui-frontend-components/calculator/) |
| **🔑 Login & Register** | Formulario responsivo de autenticación e inicio de sesión. | HTML, CSS, JS | [Ver demo 🌐](https://thiago-carollo.github.io/ui-frontend-components/login-register/) |
| **🔘 Buttons** | Colección de botones interactivos con efectos de hover y animaciones. | HTML, CSS | [Ver demo 🌐](https://thiago-carollo.github.io/ui-frontend-components/buttons/) |
| **✨ Effects** | Galería con efectos visuales para tarjetas (cards) y contenedores. | HTML, CSS | [Ver demo 🌐](https://thiago-carollo.github.io/ui-frontend-components/effects/) |
| **⚠️ Error 404** | Plantillas de diseño personalizado para páginas de error 404. | HTML, CSS | [Ver demo 🌐](https://thiago-carollo.github.io/ui-frontend-components/error-404/) |

## 🛠️ Tecnologías utilizadas

* **Estructura y Estilos:** HTML5, CSS3, SCSS (Sass).
* **Interactividad:** JavaScript (ES6+).
